# 粉尘浓度计算器

基于 GBZ/T 192 标准的粉尘浓度分析记录桌面应用。Apple Silicon 原生应用，体积仅 ~4MB。

## 产品特性

### 📊 核心计算功能

- **四舍六入五成双修约**：严格遵循 GB/T 8170 国家标准的数值修约规则
- **V0 自动换算**：当采样温度超出 5-35℃ 或气压超出 98.8-103.4 kPa 时，自动计算标准采样体积
- **多采样体积支持**：500L、300L、420L、450L、480L、525L，自动匹配对应精度

### 🔬 质控判定

| 质控项目 | 合格标准 |
|---------|---------|
| 称量质控 | 两次称量差值 ≤ 0.2 mg |
| 空白样品增重 | Δm ≤ 0.02 mg |
| 样品增重 | Δm > 0.1 mg |
| 砝码检查 | 差值 ≤ 0.1 mg |

### 📝 数据管理

- **项目级管理**：每个检测项目独立存储，包含用人单位、检测编号、环境参数等
- **样品数据录入**：支持单行录入和从 Excel 批量粘贴
- **双视图切换**：完整视图（可编辑）与誊抄视图（只读打印）
- **自动判定**：样品类型、检出状态自动计算判定

### 🎯 检出判定规则

- **空白样品**：显示"未检出"，不参与浓度计算
- **检出/未检出**：浓度值与最低定量浓度比较判定

| 采样体积 | 最低定量浓度 | 检测值精度 |
|---------|-------------|-----------|
| 500L | 0.2 mg/m³ | 1位小数 |
| 300L | 0.34 mg/m³ | 2位小数 |
| 420L | 0.24 mg/m³ | 2位小数 |
| 450L | 0.23 mg/m³ | 2位小数 |
| 525L | 0.20 mg/m³ | 2位小数 |

## 安装与运行

### 开发模式

```bash
npm install
npm run tauri:dev
```

### 构建发布版本

```bash
npm run tauri:build
```

构建产物位于 `src-tauri/target/aarch64-apple-darwin/release/bundle/dmg/` 目录。

## 使用方法

### 1. 创建项目

点击左侧「新建项目」按钮，系统自动创建一个包含默认值的新项目：
- 分析地点：天平室
- 检测依据：GBZ/T 192.1-2025
- 检验仪器：BT-125D分析天平

### 2. 填写项目信息

| 字段 | 说明 |
|-----|-----|
| 用用人单位 | 检测委托方名称 |
| 检测编号 | 项目唯一编号 |
| 分析日期 | 实验室分析日期 |
| 采样日期 | 支持日期范围（开始~结束） |
| 采样温度/气压 | 用于 V0 换算判定 |
| 分析温度/湿度 | 实验室环境记录 |

### 3. 录入样品数据

**单行录入**：
- 点击「新增行」添加样品行
- 逐项填写样品编号、滤膜编号、W1、W2（两次）

**批量粘贴（从 Excel）**：
- 在 Excel 中选中单列数据并复制
- 点击目标列的输入框
- 按 Ctrl+V（Mac: Cmd+V）粘贴
- 系统自动识别并填充多行

**样品编号规则**：
- 包含 `-0-` 的编号（如 `1-0-1`）自动识别为空白样品
- 其他编号识别为普通样品

### 4. 查看计算结果

系统自动计算并显示：
- W2 平均值（四舍六入五成双）
- 称量差值与质控判定
- 增重 Δm 与质控判定
- V0（需要换算时自动计算）
- 浓度与修约后的检测值
- 检出状态

### 5. 切换视图

- **完整视图**：可编辑所有字段，显示质控状态
- **誊抄视图**：精简显示，适合打印存档

### 6. 标准砝码检查

填写砝码编号、原始质量、本次称重，系统自动判定检查结果是否合格。

## 技术架构

- **前端**：Vue 3 + Element Plus + TypeScript
- **后端**：Tauri (Rust) + rusqlite
- **数据存储**：本地 SQLite（`~/Library/Application Support/dust-calculator/`）
- **应用体积**：~4MB（原生性能，无 Chromium 运行时）
- **支持平台**：Apple Silicon (arm64)

## 检测标准依据

- GBZ/T 192.1-2025 工作场所空气中总粉尘浓度测定
- GBZ/T 192.2-2025 工作场所空气中呼吸性粉尘浓度测定
- GB/T 8170 数值修约规则与极限数值的表示和判定
